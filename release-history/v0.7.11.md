# AutoDL Fresh 0.7.11 正式版

2026-11-12 发布（北京时间）。适用于 Windows 10 / 11 x64。

- 当平台返回 HTTP 200、错误码为 `InternalError` 且创建结果为空时，候租会按原间隔刷新库存、重新选机和核价。明确的余额、权限等错误仍会提示处理，提交结果不明时保留待核验记录。
- 只候租一种 GPU 时，重新勾选型号后才读取与目标型号匹配的库存。筛选过程中出现的全部型号列表和迟到的旧结果会被跳过。

旧版可通过软件内的「检查更新」下载。手动升级时，从系统托盘退出旧版，解压完整的 `AutoDLFresh` 文件夹并运行其中的 `AutoDLFresh.exe`。登录态、偏好设置和运行历史存放在独立数据目录中，可直接沿用。

随附 `SHA256SUMS.txt` 和第三方源码包。各版本的详细改动见 [更新日志](https://github.com/wanfeng562-code/autodl-fresh/blob/main/CHANGELOG.md)。
