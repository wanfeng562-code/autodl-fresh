# AutoDL Fresh 0.7.8 正式版

发布日期：2026-10-30（北京时间）。Windows 10 / 11 x64，保留非商业使用许可及第三方许可说明。

## 此次更新

本版本将 0.7.0–0.7.8 的 GPU 候租功能和修复整理为正式版，并保留 0.6.0 的实例保活、每日计划及软件内检查更新功能。

- **GPU 候租**：选择已关机源实例、同地区可接受 GPU、优先顺序和卡数；默认每秒通过网页勾选操作检查库存，找到后克隆系统盘与数据盘，创建并开机一台实例。
- **库存竞争重试**：创建时 GPU 被抢走且平台明确未接受创建，继续候租；响应不确定时保留记录，避免重复下单。
- **报价缓存**：内置西北 B 区 20 个型号的 JSON 参考报价，启动即可读取；仅在手动点击“重新核对报价”时联网完整读取，通常至少需要两分钟。
- **后台操作**：读取实例和地区报价使用专用浏览器最小化操作；浏览器账号、同步和用户扩展与日常浏览器隔离。
- **创建结果提醒**：创建成功返回新实例 ID 后通知用户，仅定向等待该实例的克隆和数据盘拷贝完成，结束后关闭专用浏览器。
- **人工确认**：等待期间也可点击“确认克隆已完成”或“确认实例已释放”，无需输入 ID；记录人工结果并解除暂停，重新候租需手动开始。
- **已释放实例处理**：连续三次成功查询未找到实例，或检测到释放状态时，结束自动等待并提示手动确认。

## 下载与升级

- 下载 `AutoDLFresh-0.7.8-windows-x64.zip`，解压整个 `AutoDLFresh` 文件夹，运行 `AutoDLFresh.exe`。不要单独移动 exe。
- 从旧版升级前，请先完成当前任务并从系统托盘退出旧程序，再运行新版本。登录态、配置和历史位于独立数据目录，继续复用。
- 旧版点击“检查更新”可检测并下载 0.7.8；下载会验证 SHA-256，之后由用户退出旧程序、解压并启动新版。
- `SHA256SUMS.txt` 提供附件校验值；`AutoDLFresh-0.7.8-third-party-sources.zip` 提供随程序使用的 Qt / PySide6 对应源码。
- 新租用实例会继续按平台规则计费，由用户使用后关机。首次登录与人机验证需手动完成。

完整逐版本改动见 [更新日志](https://github.com/wanfeng562-code/autodl-fresh/blob/main/CHANGELOG.md)。
